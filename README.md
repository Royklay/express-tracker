# Expense Tracker 

## About the Project

The Expense Tracker is a simple web application built to help users manage and keep track of their daily spending.

Users can add expenses by entering a description, amount, and category. They can also view their expenses, filter them by category, delete expenses, and see their total spending for the current day.

## Live Demo

**Live Website:**  https://royklay.github.io/express-tracker/

## Features

- **Add Expenses:** Record expenses using a description, amount, and category.
- **View Expenses:** Display all recorded expenses in an organized list.
- **Delete Expenses:** Remove expenses that are no longer needed.
- **Category Filtering:** Filter expenses by Food, Transport, Shopping, Bills, or Other.
- **Daily Total:** Automatically calculate the total expenses recorded today.
- **Local Storage:** Save expenses in the browser so they remain available after refreshing the page.

## Technologies Used

- HTML5 – Used to structure the webpage.
- CSS– Used to style the application.
- JavaScript – Used to handle expense management and application functionality.
- Local Storage – Used to save expense records in the browser.
- JSON – Used to convert expense data into a format that can be stored and retrieved from Local Storage.

## How to Use

1. Open the Expense Tracker website.
2. Enter an expense description.
3. Enter the amount spent.
4. Select an expense category.
5. Click the Add Expense button.
6. View your recorded expenses under My Expenses.
7. Use the category filter to find specific expenses.
8. Click Delete to remove an expense.
